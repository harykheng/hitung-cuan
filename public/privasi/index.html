Kebijakan Privasi HitungCuan

Terakhir diperbarui: 23 Oktober 2026

HitungCuan dikelola oleh Studio Harel. Halaman ini menjelaskan data apa yang dikumpulkan, data apa yang sengaja tidak diambil, siapa yang bisa melihatnya, dan berapa lama data disimpan. Aturan pemakaian ada di Syarat Layanan.

1. Halaman web ini

  • Simulator dihitung di browser kamu. Angka yang kamu isi tidak dikirim atau disimpan.
  • Halaman ini tidak memasang cookie dan tidak memakai penyimpanan lokal browser. Font dimuat dari server yang sama, bukan dari layanan font luar.
  • Halaman dilayani lewat Cloudflare. Seperti semua server web, penyedia hosting memproses permintaan koneksi (misalnya alamat IP) supaya halaman bisa sampai ke perangkatmu.

Statistik kunjungan (Umami)

  • Untuk menghitung jumlah kunjungan dan klik tombol, halaman ini memuat skrip statistik Umami Cloud (layanan dari Umami Software). Skrip ini tidak memasang cookie dan tidak menulis ke penyimpanan lokal browser.
  • Yang dikirim ke Umami: alamat halaman yang dibuka (termasuk kode sumber seperti ?src=), halaman asal kamu datang, judul halaman, ukuran layar, dan bahasa browser.
  • Juga dicatat: halaman dibuka, tombol WhatsApp ditekan beserta letak tombolnya, tombol salin nomor ditekan, simulator dipakai (tanpa angkanya), dan seberapa jauh halaman digulir.
  • Seperti layanan web lain, Umami menerima koneksi dari perangkatmu, sehingga dapat membaca jenis browser, sistem operasi, jenis perangkat, dan perkiraan lokasi dari alamat IP. Data ini diproses oleh Umami sesuai kebijakan privasi mereka.
  • Nama, nomor WhatsApp, dan isi pesanmu tidak dikirim ke Umami.

Tombol WhatsApp

  • Tombol membuka WhatsApp dengan pesan yang sudah terisi. Pesan baru terkirim kalau kamu menekan kirim. Untuk tombol di simulator, angka simulasimu ikut tertulis di pesan.
  • Kalau kamu membuka halaman lewat tautan yang memuat ?src=, kode itu ikut tertulis di akhir pesan sebagai "Kode: HC-...", supaya kami tahu dari mana kamu datang.
  • Setelah terkirim, nomor WhatsApp dan isi pesanmu diterima admin dan diproses oleh WhatsApp sesuai kebijakan WhatsApp sendiri.

2. Aplikasi HitungCuan (setelah akunmu dibuat)

Akun dibuat manual oleh admin setelah kamu chat. 1 akun dipakai untuk 1 toko.

Data yang disimpan

  • Akun: email dan kata sandi untuk masuk. Proses masuk berjalan lewat Supabase Auth.
  • Pesanan (dari file export pesanan): nomor pesanan, nama produk dan variasi, SKU, jumlah, status pesanan, status pembatalan atau pengembalian, waktu pesanan dibuat dan selesai, dan subtotal per item.
  • Penghasilan (dari laporan penghasilan PDF): angka penghasilan per tanggal dana dilepas, dan keterangan serta jumlah biaya penyesuaian.
  • Iklan (dari file data iklan): nama toko di file, periode, nama iklan atau grup, kode dan nama produk, jumlah dilihat, klik, produk terjual, omzet, dan biaya.
  • Yang kamu isi sendiri: HPP per produk, biaya bulanan (iklan Shopee, Meta Ads, packaging, lain-lain) beserta catatan yang kamu tulis, persen admin serta Gratis Ongkir XTRA per produk, kategori biaya admin beserta persennya, dan pengaturan hitungan toko (target untung dan porsi barang retur yang bisa dijual lagi).
  • Riwayat unggah: akun mana yang mengunggah data dan kapan.
  • Laporan error: kalau aplikasi mengalami gangguan, browsermu mengirim laporan berisi pesan error, bagian kode tempat error terjadi, halaman yang sedang dibuka, versi aplikasi, dan jenis browser, terhubung ke akun dan tokomu. Isi file tidak ikut dikirim, tetapi pesan error kadang menyebut sebagian data yang memicunya, misalnya tanggal atau kode produk. Laporan ini hanya bisa dibaca admin, dan dipakai untuk memperbaiki aplikasi.

Data ini dipakai untuk menghitung dan menampilkan rekap untung, penilaian iklan, dan simulasi harga di akunmu. Nomor pesanan memang tersimpan. Nomor itu bukan nama pembeli, tetapi bisa dicocokkan dengan pesanan di Seller Centre milikmu.

Di browsermu, aplikasi menyimpan sesi login (supaya kamu tidak perlu masuk ulang setiap membuka aplikasi), toko yang terakhir dipilih, dan pengingat yang kamu tunda. Aplikasi tidak memakai cookie iklan dan tidak memuat skrip statistik.

Data pembeli yang tidak diambil

File export pesanan Shopee memuat data pribadi pembeli. Kolom-kolom berikut tidak diambil, tidak dikirim, dan tidak disimpan oleh aplikasi:

  • username pembeli
  • nama penerima
  • nomor telepon
  • alamat pengiriman, kota atau kabupaten, dan provinsi
  • catatan dari pembeli
  • nomor resi dan Booking SN

File dibaca di browser kamu. File aslinya tidak diunggah ke server. Browser memang memuat seluruh isi file ke memori saat membacanya, tetapi kolom di atas tidak diteruskan. File data iklan tidak memuat data pembeli.

3. Siapa yang bisa melihat datamu

  • Akunmu sendiri, setelah login. Data tidak bisa dibaca atau ditulis tanpa login.
  • Admin HitungCuan, yang mengelola database dan bisa mengaksesnya untuk membantu kamu, misalnya menghapus data atas permintaanmu.
  • Supabase, penyedia database dan sistem login yang menyimpan data aplikasi atas nama kami.
  • Seller lain tidak bisa melihat atau mengubah datamu. Data semua seller HitungCuan disimpan di satu database yang sama, dan setiap baris data ditandai dengan toko pemiliknya. Database hanya mengizinkan akun yang terdaftar di toko itu untuk membaca atau mengubahnya (aturan akses per baris, row level security). Aturan ini dijalankan di dalam database, bukan hanya oleh tampilan aplikasi, jadi tetap berlaku walaupun seseorang mengakses database tanpa lewat aplikasi.

4. Berapa lama data disimpan

  • Selama kamu berlangganan.
  • Setelah uji coba atau langgananmu berakhir, akunmu otomatis menjadi mode baca saja (Rekap masih bisa dilihat, data tidak bisa diubah). Datamu tetap tersimpan, dan kalau sudah 3 bulan kamu tidak berlangganan, datamu dihapus.
  • Mau dihapus lebih cepat? Hubungi admin lewat WhatsApp, dan datamu dihapus atas permintaanmu.

5. Permintaan dan pertanyaan tentang datamu

Untuk meminta penghapusan data, atau bertanya apa yang tersimpan tentang tokomu, hubungi admin lewat WhatsApp.

6. Perubahan kebijakan

Kalau cara kami mengelola data berubah, halaman ini diperbarui dan tanggal "Terakhir diperbarui" di atas ikut berubah.
